# jornada

## requirements

- Node.js (any recent LTS) — runs `npm run init` and `npm run pull`
- git, with SSH access configured for the private submodules

## first step

```
npm run init
```

## pull everything

```
npm run pull
```

Downloads every area submodule and prints what each hash resolves to,
reading the mapping from `00-proxy`.

## rules

All rules and reference material for this repository live inside `00-proxy/`.
Anything you need to look up is there — consult it before doing anything here.
