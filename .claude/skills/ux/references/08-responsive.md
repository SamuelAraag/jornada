# Responsividade

- Faixa obrigatória de suporte: 320px até desktop (sem limite superior fixo, mas testar
  também em ~1280px e ~1440px).
- Breakpoints de referência: 320px (mobile), 768px (tablet), 1280px (desktop).
- Tabelas em telas estreitas: preferir colapsar colunas secundárias antes de forçar scroll
  horizontal. Scroll horizontal só é aceitável quando a comparação entre colunas é o
  propósito central da tela (ex.: planilha financeira).
- Filtros que ficam em linha no desktop colapsam para um painel/drawer expansível no
  mobile — nunca empilhados ocupando a tela toda de forma que esconda o conteúdo.
- Ações de tabela (ícones/botões) precisam de área de toque mínima adequada em telas
  touch — não depender de hover para revelar ações em mobile.
- Formulários em mobile usam uma coluna; múltiplas colunas só a partir do breakpoint
  tablet.
